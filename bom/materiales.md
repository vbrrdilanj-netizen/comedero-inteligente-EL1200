Lista de materiales
Para desarrollar la simulación del comedero inteligente se utilizan los siguientes componentes electrónicos:
Cantidad|Componente|Función
1| ESP32	|Controla el funcionamiento del sistema.
1|Sensor PIR|Detecta movimiento frente al comedero.
1|Servomotor|	Representa la apertura y el cierre del dispensador.
1|LED rojo|	Indica cuándo se está dispensando alimento.
1|Resistencia de 220 Ω|Limita la corriente que circula por el LED.
|Según necesidad|	Cables de conexión|Permiten conectar los componentes al ESP32.

El proyecto se desarrolla mediante la plataforma Wokwi, por lo que los componentes se utilizan de forma virtual.
Esta lista corresponde a los elementos necesarios para representar el funcionamiento básico del comedero inteligente.
